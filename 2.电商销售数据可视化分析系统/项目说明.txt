========================================
电商销售数据可视化分析系统
========================================


运行：在python终端输入： python -m streamlit run app.py
注意，不能直接运行要打开终端


一、项目介绍
本项目是一个基于Python的电商销售数据分析与可视化系统，
通过Streamlit构建交互式仪表盘，帮助用户从海量交易数据中
挖掘商业价值，辅助运营决策。

项目实现了以下核心功能：
1. 数据清洗：自动处理缺失值、重复订单、异常值，将原始
   数据转换为可分析的标准格式
2. 多维度分析：从时间（月/周）、商品品类、地区三个维度
   全面分析销售数据，生成GMV、订单量、客单价等关键指标
3. 可视化展示：通过折线图、饼图、柱状图、箱线图等多种
   图表直观展示分析结果，支持交互式筛选和联动
4. 报表导出：一键生成HTML格式分析报告，便于分享和汇报

适用场景：电商平台运营分析、销售数据监控、商业决策支持

二、技术栈
- pandas: 数据清洗与分析
- matplotlib/seaborn: 数据可视化
- streamlit: 交互式Web界面
- numpy: 数值计算

三、功能模块

1. 数据加载与清洗
   - 支持CSV/Excel文件上传
   - 缺失值处理（删除/填充）
   - 重复订单去除
   - 时间格式转换
   - 异常值检测（IQR方法+负数检测）

2. 多维度统计分析
   - 销售趋势：按月/周统计GMV和订单量
   - 商品分析：品类销量占比、销售额Top10排名
   - 地区分析：购买力分布、客单价对比

3. 可视化展示
   - 折线图：销售趋势分析
   - 饼图：品类占比分析
   - 柱状图：排名与地区对比
   - 箱线图：异常值分布分析

4. 报表导出
   - HTML格式分析报告导出

四、文件说明
- app.py: 主程序文件
- sales_data.csv: 示例数据（含5000+条订单记录）
- requirements.txt: Python依赖包列表
- run.bat: Windows一键启动脚本
- 项目说明.txt: 本文件

五、使用方法
1. 安装依赖：pip install -r requirements.txt
2. 启动系统：双击 run.bat 或在终端执行
   python -m streamlit run app.py
3. 浏览器访问：http://localhost:8501
4. 上传CSV/Excel文件开始分析

六、数据字段说明
- 订单号：唯一订单标识（如ORD2024000001）
- 商品类别：电子产品、服装、家居用品等8个品类
- 销售金额：订单交易金额（元）
- 地区：华东、华南、华北等7大区域
- 时间：订单日期（2024年1月-12月）

七、注意事项
- 首次运行需安装依赖包
- 数据文件建议不超过50MB
- 支持GBK和UTF-8编码的CSV文件
- 异常值检测基于IQR方法，可自定义阈值
