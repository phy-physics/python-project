随着人工智能和计算机视觉技术的快速发展，人脸识别技术已经广泛应用于各个领域，包括安防监控、门禁系统、身份验证、智能支付等。传统的身份验证方式如密码、IC卡等存在易丢失、易被盗用等问题，而人脸识别作为一种生物特征识别技术，具有唯一性、稳定性和便捷性等优势，逐渐成为身份认证的主流方式。
本项目基于 Python 编程语言，结合 
face_recognition
 深度学习库和 OpenCV 计算机视觉库，设计并实现了一个完整的人脸识别门禁系统原型。系统采用深度学习模型提取人脸的128维特征向量，通过计算特征向量之间的欧氏距离来判断身份，实现了从人脸采集、特征提取、身份识别到日志管理的完整流程。
1.2 
项目目标
本项目的主要目标包括：
（1）实现基于深度学习的高精度人脸识别算法
（2）开发友好的图形用户界面，方便用户操作
（3）实现实时人脸检测和识别功能
（4）建立完整的人脸数据库管理系统
（5）实现通行日志的记录和查询功能
（6）保证系统的实时性和稳定性
1.3 
主要功能
系统实现了以下核心功能：
（1）人脸录入：通过摄像头实时采集用户人脸图像，自动检测人脸位置，提取128维特征向量并保存到数据库中。支持多人脸录入，每个用户只需
采集约
30张样本即可完成注册。
（1）人脸识别：实时检测摄像头画面中的人脸，提取特征向量并与数据库中的人脸进行比对，判断是否为授权用户。识别结果以可视化方式显示在界面上。
（1）通行日志：自动记录每次识别的时间、姓名和通行状态（允许通行/拒绝通行），支持按姓名搜索、刷新和清空日志。
（1）图形界面：提供直观的 GUI 界面，包含摄像头实时预览、功能按钮和状态显示，用户无需编程知识即可操作。
二、
技术背景
2.1 
人脸识别技术简介
人脸识别技术是计算机视觉和模式识别领域的重要研究方向，其基本流程包括以下几个步骤：
（1）人脸采集：采集人脸图片的方法多种多样，可以直接从网上下载数据集，可以从视频中提取图片，还可以从摄像头实时采集图片。本系统采用摄像头实时采集的方式，通过 OpenCV 的 
VideoCapture
 接口获取摄像头视频流。
（1）人脸检测：人脸检测在实际中主要用于人脸识别的预处理，即在图像中准确标定出人脸的位置和大小。本系统使用 OpenCV 的 Haar 级联分类器进行人脸检测，该方法基于 AdaBoost 算法，通过训练大量正负样本得到强分类器，具有速度快、准确率高的特点，适合实时应用。
（1）人脸特征提取：将检测到的人脸区域转换为可用于识别的特征表示。传统方法包括 
EigenFaces
（主成分分析）、
FisherFaces
（线性判别分析）和 LBPH（局部二
值模式
直方图）等。本系统采用 
face_recognition
 库（基于 
dlib
 的深度学习模型）提取人脸的128维特征向量，该方法使用在 LFW 数据集上训练的深度学习神经网络，具有更高的识别精度和鲁棒性。
（1）匹配与识别：提取的人脸特征向量与数据库中存储的特征模板进行比对，通过计算欧氏距离判断相似度。当距离小于阈值（0.6）时，判定为同一人。这一过程分为两类：一类是确认（Verification，一对一比对），另一类是辨认（Identification，一对多比对）。本系统采用辨认模式，即与数据库中所有人
脸进行
比对，找到最匹配的结果。
2.2 
face_recognition
 库介绍
face_recognition
 是一个基于 
dlib
 库的 Python 人脸识别库，由 Adam Geitgey 开发。它使用了在 LFW（Labeled Faces in the Wild）数据集上训练的深度学习模型，该模型基于 
ResNet
 架构，准确率达到 99.38%。
该库的主要功能包括：
• 
face_recognition.face_locations
()：检测图像中的人脸位置，返回人脸的边界框坐标（上、右、下、左）。支持多种检测模型，包括 Hog 和 CNN。
• 
face_recognition.face_encodings
()：提取人脸的128维特征向量，用于后续的身份识别。该函数接收图像和人脸位置作为输入，返回一个包含特征向量的列表。
• 
face_recognition.face_distance
()：计算两个人脸特征向量之间的欧氏距离，距离越小表示越相似。通常将阈值设为 0.6，距离小于该值判定为同一人。
• 
face_recognition.compare_faces
()：比较已知人脸编码列表与待识别的人脸编码，返回布尔值列表表示是否匹配。

三、
系统设计
3.1 
系统架构
本系统采用多线程架构设计，主要包括以下模块：
系统整体架构如下图所示：
（1）主线程（GUI线程）：负责图形界面的更新和摄像头帧的读取，使用 
Tkinter
 构建用户界面
（2）人脸录入线程：负责采集新人脸图像并提取特征向量，采集完成后保存到数据库
（3）人脸识别线程：负责实时检测并识别摄像头画面中的人脸，返回识别结果
（4）数据存储模块：负责保存和加载人脸特征向量及配置文件，使用 pickle 序列化
（5）日志管理模块：负责记录和管理通行日志，使用 CSV 格式存储
3.2 
功能模块设计
系统主要包含以下功能模块：
（1）初始化模块：系统启动时读取配置文件 config.txt 和特征向量文件 
encodings.pkl
，加载已知人脸信息到内存中。同时加载 OpenCV 的 Haar 级联分类器模型文件，初始化摄像头。
（1）人脸录入模块：通过摄像头采集30张人脸样本，使用 Haar 级联检测人脸位置，对每张检测到的人脸使用 
face_recognition
 提取128维特征向量，计算所有样本的平均特征向量作为该用户的特征模板，保存到 
encodings.pkl
 文件中。
（1）人脸识别模块：实时检测摄像头画面中的人脸，提取特征向量并与数据库中所有已知人脸进行比对，计算欧氏距离找到最匹配的结果。统计30帧内的匹配结果，返回匹配次数最多的用户ID。
识别结果以可视化方式显示在界面上。
（1）通行日志模块：每次识别完成后，将时间、姓名和通行状态记录到 CSV 文件中。提供查询界面，支持按姓名搜索、刷新列表和清空日志。
（1）GUI界面模块：使用 
Tkinter
 构建图形界面，包含摄像头实时预览区域、功能按钮（开始刷脸、录入人脸、通行日志、退出）和状态显示标签。
3.3 
多线程设计
为避免界面卡顿，系统采用多线程架构：
• 
video_loop
()：主线程，负责摄像头读取和 GUI 更新，每秒约30帧。使用 
window.after
(1, 
video_loop
) 实现循环调用，确保界面流畅。
• 
f_rec_face_thread
()：工作线程，负责人脸录入。采集30张样本并提取特征向量，完成后更新配置文件和特征数据库。
• 
f_scan_face_thread
()：工作线程，负责人脸识别。检测30帧并统计匹配结果，返回匹配次数最多的用户ID。

 作为互斥锁，确保录入和识别不会同时进行：

4.2 
人脸录入模块
人脸录入模块的主要功能是通过摄像头采集用户的人脸图像，提取特征向量并保存到数据库中。具体实现步骤如下：
（1）创建数据目录：清空或创建 data 目录用于存储采集过程中的人脸截图。每次录入
前清空该目录
，确保只保存本次采集的样本。
（2）采集人脸样本：循环采集30张人脸图像。复用主线程 
video_loop
 中更新的 
img
 变量，避免多线程同时读取摄像头导致的数据冲突。使用 Haar 级联检测人脸位置，并用矩形框标记。
（3）提取特征向量：对每张检测到的人脸，使用 
face_recognition.face_encodings
() 提取128维特征向量。将特征向量保存到 
encodings_list
 列表中。
（4）计算平均特征：采集完成后，将所有样本的特征向量求平均，作为该用户的特征模板。这样可以减少单次检测的误差，提高识别稳定性。
（5）保存特征向量：将特征模板以 pickle 格式保存到 
encodings.pkl
 文件中，便于下次启动时加载。
（6）更新配置文件：修改 config.txt，更新人脸总数（第一行加一）和 id-姓名对应关系（追加新记录）。

4.3 
人脸识别模块
人脸识别模块是系统的核心功能，其实现流程如下：
（1）从摄像头获取当前
帧
图像（复用主线程的 
img
 变量）
（2）使用 Haar 级联分类器检测人脸位置
（3）对检测到的人脸区域，使用 
face_recognition
 提取128维特征向量
（4）遍历所有已知人脸的特征向量，计算欧氏距离
（5）找到距离最小的匹配，若距离 &lt; 0.6 则判定为同一人
（6）统计30帧内的匹配结果，返回匹配次数最多的用户ID

系统支持将每次识别结果保存到 CSV 文件，并提供查询界面。日志记录包含以下信息：
（1）时间：识别发生的精确时间（格式：YYYY-MM-DD HH:MM:SS）

七、
实验结果与分析
本系统在实际测试中表现出良好的识别性能和稳定性。以下是实验结果分析：
7.1 
识别准确率分析
face_recognition
 库基于深度学习模型，在 LFW 数据集上的准确率达到 99.38%。在本系统的实际测试中：
（1）对已录入用户，识别准确率较高，置信度通常在 80% 以上。系统通过统计30帧内的匹配结果，进一步提高了识别的可靠性。
（2）对未录入人员，系统能正确识别为"未知人员"，拒绝通行。欧氏距离阈值设为 0.6，有效区分了已知和未知人脸。
（3）在正常光照条件下，识别效果稳定可靠。Haar 级联检测器能够快速准确地定位人脸位置。
（4）通过采集30张样本并计算平均特征向量，减少了单次检测的误差，提高了识别稳定性。
7.2 
识别速度分析
系统采用 Haar 级联进行人脸检测，结合 
face_recognition
 提取特征，整体识别速度满足实时性要求：
（1）人脸检测：Haar 级联分类器检测速度快，可实时处理视频流，单帧检测时间约几毫秒。
（2）特征提取：
face_recognition
 提取128维特征向量约需几十毫秒，取决于 CPU 性能。
（3）特征比对：欧氏距离计算简单快速，与数据库中每个人脸比对的时间可忽略不计。
（4）整体识别流程：30帧统计约需 2-3 
秒完成
一次识别，满足门禁系统的实时性要求。
7.3 
系统稳定性分析
系统采用多线程架构和互斥锁机制，保证了运行的稳定性：
（1）多线程设计避免界面卡顿，用户体验良好。主线程负责界面更新，工作线程负责计算密集型任务。
（2）互斥锁机制防止录入和识别同时进行，避免数据冲突。
system_state_lock
 变量确保同一时间只有一个操作在执行。
（3）工作线程复用主线程的图像帧，避免多线程同时读取摄像头导致的数据竞争。
（4）异常处理机制保证系统在异常情况下不会崩溃，如摄像头断开、文件不存在等情况都有相应的处理。
八、
总结与展望
8.1 
项目与总结
本项目成功实现了一个基于深度学习的人脸识别系统。系统采用 
face_recognition
 库提取人脸的128维特征向量，结合 OpenCV 的 Haar 级联分类器进行人脸检测，实现了人脸录入、实时识别和通行日志管理等功能。通过多线程架构设计，系统保证了良好的实时性和用户体验。
系统的主要优点包括：
（1）识别精度高：基于深度学习的特征提取方法，在 LFW 数据集上准确率达99.38%
（2）实时性好：多线程架构保证界面流畅，识别速度快，满足门禁系统需求
（3）功能完整：涵盖人脸录入、识别、日志管理等完整流程，可直接使用
（4）易于扩展：模块化设计便于后续功能扩展，代码结构清晰
（5）用户友好：提供直观的 GUI 界面，无需编程知识即可操作
8.2 
未来改进方向
尽管系统已经实现了基本的人脸识别功能，但仍有以下改进空间：
（1）活体检测：增加活体检测功能，防止照片或视频攻击，提高系统安全性
（2）多模态识别：结合其他生物特征（如虹膜、指纹）提高识别准确性和安全性
（3）云端部署：将特征数据库部署到云端，支持分布式识别和跨设备同步
（4）移动端适配：开发移动端应用，方便在手机上使用，扩展应用场景
（5）性能优化：使用 GPU 加速特征提取，提高识别速度，支持更大规模的人脸库
（6）光照自适应：增加图像预处理模块，提高在复杂光照条件下的识别率
